AMJNR MARKETPLACE — FREE FIRST WEBSITE
=======================================

This is the first static/mobile-friendly version of Amjnr. It includes:
- Amjnr branding and logo
- 5 promotional sliders
- Categories
- Sample products
- Add-to-cart demo counter
- Seller call-to-action
- Search/cart modal demo
- Newsletter form demo

IMPORTANT:
This is a FRONT-END STARTER, not yet a real multi-vendor marketplace. Payments,
real seller accounts, database, product management, orders and delivery need a
backend and payment integration before launch.

FREE HOSTING OPTION — GITHUB PAGES
----------------------------------
1. Create a free GitHub account.
2. Create a repository named: amjnr.github.io
3. Upload ALL files and the assets folder from this package.
4. In repository Settings -> Pages, select deployment from the main branch/root.
5. GitHub will give you a free address like https://amjnr.github.io

If GitHub says the repository name is already taken, choose another free name,
for example amjnr-marketplace, and the site can be published at a corresponding
GitHub Pages address.
