AMJNR MARKETPLACE — V2 STARTER
===============================

V2 adds a richer local product catalog and customer-facing interactions.

Included:
- 12 Nigerian-marketplace sample products across 6 categories
- Custom vector product artwork in assets/products.svg
- Product badges, ratings, seller names, prices and discounts
- Category filtering
- Product search
- Add-to-cart with localStorage persistence
- Cart summary and total
- Mobile-friendly product grid
- Mobile promotional banner remains fixed at 2.05:1

This is still a static front-end. Checkout, customer accounts, seller dashboards,
payments, orders and delivery tracking require later backend/database work.

Deployment:
- GitHub repository: keep index.html, style.css, script.js at the root
- Keep assets/ and assets/products.svg intact
- Cloudflare Pages: main branch, framework None, build command `exit 0`, output directory root
